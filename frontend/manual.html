System Overview

The Resource Scheduler is a comprehensive workforce management system designed to optimize staff allocation across projects. It enables organizations to efficiently schedule employees based on their skills, availability, and project requirements.

Key Features

People Management

Manage employee profiles, skills, and availability with detailed proficiency tracking.

Project Management

Create projects with skill requirements and track resource allocation.

Smart Scheduling

Create assignments with hourly time slots and automatic conflict detection.

AI Optimization

Let AI suggest optimal schedules based on skills, availability, and priorities.

Conflict Detection

Automatically detect scheduling conflicts, overallocation, and skill gaps.

Reporting

Generate comprehensive reports with preview and PDF export capabilities.

Quick Tip

Press ? on any page to see context-sensitive help for that specific feature.

Dashboard

The Dashboard provides a real-time overview of your organization's scheduling status with key metrics and visualizations.

Metrics Overview

Metric Description
Active People Total number of active employees in the system
Active Projects Number of projects currently in "Active" status
Today's Assignments Number of assignments scheduled for today
Unresolved Conflicts Scheduling conflicts that need attention

Dashboard Widgets

  • Today's Overview: Quick stats about today's schedule including utilization rate
  • Conflicts by Type: Breakdown of unresolved scheduling conflicts
  • Weekly Hours Trend: Chart showing hours scheduled over the past week
  • Top Utilized: Most active employees by hours worked
  • Project Workload: Projects with the most scheduled hours

Pro Tip

Click on any metric card to navigate directly to the related page for more details.

Schedule View

The Schedule view displays assignments in a timeline format, allowing you to see who is working on what project at any given time.

View Options

Daily View

Shows all assignments for a single day with hourly breakdown (6 AM - 10 PM).

Weekly View

Overview of the entire week showing assignments across all days.

Creating an Assignment

Click "Add Assignment"

Use the button in the top-right corner or click directly on a time slot.

Select Person & Project

Choose who you're assigning and to which project.

Set Date & Time

Pick the date and specify start/end hours for the assignment.

Add Task Description (Optional)

Describe what work should be done during this assignment.

Navigation

  • Previous/Next: Navigate between days using arrow buttons
  • Today: Jump back to today's date
  • Date Picker: Select any specific date

Quick Navigation

Click on a person's name in the timeline to view their full profile and availability.

People Management

Manage your workforce by adding employees, tracking their skills, and monitoring their availability.

Person Profile Fields

Field Required Description
First Name Yes Employee's first name
Last Name Yes Employee's last name
Email Yes Unique email address
Department No Organizational department
Job Title No Position or role
Max Hours/Day No Maximum working hours per day (default: 8)
Employment Type No Full-time, Part-time, Contractor, or Intern

Assigning Skills

Each person can have multiple skills with proficiency levels:

  • Level 1: Beginner - Basic understanding
  • Level 2: Elementary - Can work with guidance
  • Level 3: Intermediate - Can work independently
  • Level 4: Advanced - Expert knowledge
  • Level 5: Master - Can teach others

Actions

  • View Details: Click on a person card to see full profile
  • Edit: Modify person information and skills (Admin/Manager only)
  • Delete: Remove person from system (Admin only)
  • Search: Filter by name or email
  • Filter: Show only active or inactive employees

Project Management

Create and manage projects with detailed skill requirements and staffing needs.

Project Fields

Field Description
Name Project title (required)
Code Unique project identifier (e.g., PRJ-001)
Client Client or customer name
Status Planning, Active, On-Hold, or Completed
Priority Low, Medium, High, or Critical
Budget Hours Total hours allocated for the project

Skill Requirements

For each project, you can specify which skills are needed:

  • People Needed: How many people with this skill are required
  • Minimum Level: Required proficiency level (1-5)
  • Required/Optional: Whether the skill is mandatory

Find Candidates

Use the "Find Candidates" feature to automatically discover the best matches for your project based on required skills and availability.

Skill Matching

The system scores candidates based on their skill proficiency, availability, and current workload to suggest optimal assignments.

Skills Management

Define the skills available in your organization and categorize them for easy management.

Skill Properties

  • Name: Unique skill name (e.g., "JavaScript", "Project Management")
  • Category: Grouping (e.g., "Programming", "Soft Skills", "Design")
  • Color: Visual identifier for quick recognition
  • Description: Detailed explanation of the skill

Skill Statistics

Each skill card displays:

  • Number of people with this skill
  • Number of projects requiring this skill

Skill Gaps

When more projects require a skill than people have it, this indicates a skill gap. Consider training or hiring to address gaps.

AI Schedule Optimizer

Let artificial intelligence analyze your projects, skills, and availability to generate optimal schedule suggestions.

How It Works

Select Date Range

Choose the start and end dates for schedule generation.

Generate Suggestions

Click the button to let AI analyze and create optimal assignments.

Review Suggestions

Each suggestion shows project, person, skill match, and time slot.

Apply or Modify

Accept individual suggestions, reschedule to different people, or apply all at once.

Suggestion Actions

Button Action
Accept Create this assignment
Reschedule Assign to a different person
Remove Discard this suggestion

AI Considerations

The AI optimizer takes into account:

  • Project priority (Critical/High projects are scheduled first)
  • Skill match score (proficiency level vs. required level)
  • Person availability (excludes those on leave)
  • Workload balance (prefers people with available hours)
  • Existing assignments (avoids time conflicts)

Match Score

The percentage shown indicates how well a person matches the requirement. 70%+ is considered a good match.

Conflict Detection

The system automatically detects scheduling issues to help maintain an optimal and conflict-free schedule.

Conflict Types

Type Description Severity
Overlap Same person assigned to multiple projects at the same time Critical
Overallocation Person scheduled for more hours than their daily maximum Error
Skill Gap Person lacks required skill for assigned project Warning
Availability Person assigned during time-off or vacation Error
Max Hours Daily hour limit exceeded Warning
Max Projects Person assigned to too many projects in one day Info

Resolving Conflicts

  • Review the conflict description to understand the issue
  • Modify or delete the conflicting assignment
  • Mark as resolved once addressed
  • Use "Re-detect" to scan for new conflicts

Reports & Exports

Active Projects Summary

Displays all active projects with:

  • Project details (name, code, client, priority)
  • Total hours worked

Report Preview

Export Options

Print / PDF

Role-Based Access Control

The system implements role-based access control (RBAC) to ensure users only access features appropriate to their responsibilities.

Role Descriptions

Admin

Full system access. Can manage users, configure settings, and perform all operations including deletions.

Manager

Can manage people, projects, and skills. Full scheduling capabilities but no user management.

Scheduler

Focused on scheduling operations. Can create and manage assignments, use AI scheduler, and export reports.

Viewer

Read-only access. Can view all data but cannot make changes. Ideal for stakeholders and reviewers.
